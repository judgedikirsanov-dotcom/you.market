честный поиск товаров

жмёшь «искать» — я открываю окна поисковиков с твоим запросом (Google, Яндекс, Bing, DuckDuckGo) каскадом, друг под другом, и поверх — окно поиска с живым прогрессом. Выдача вместе с ИИ-ответом прилетает с твоих окон, они закрываются сами, и ты остаёшься на моей странице с отфильтрованными карточками и медианой рынка. Всё выполняется от твоего лица: твой браузер, твой IP, твои куки — поисковик видит обычного тебя.
🔒 приватно: страница — статический HTML без серверов, прокси и логов. Запросы к магазинам идут с твоего IP (у них CORS открыт); выдача поисковиков попадает на страницу только из твоих вкладок — через postMessage от кнопки-закладки или твой буфер обмена. Мы не конкуренты поисковикам — мы их продвинутые пользователи, работаем от лица обычного человека.

⚙️ разовая настройка (1 минута) — чтобы окна сами приходили с выдачей

  1. кнопка-закладка — универсально, любой браузер (Firefox, Chrome, Safari…), без расширений: перетащи эту кнопку на панель закладок (в Firefox: Ctrl+Shift+B — показать панель):
    📨 в фильтр товаров
    потом на любой странице выдачи — один клик по этой закладке: окно само отправит результаты и ИИ-ответ на главную страницу и закроется. Если окно открыл вручную — закладка положит выдачу в буфер, вернись и нажми Ctrl+V. На телефоне: открой закладку из меню закладок.
  2. или пользовательский скрипт (Firefox/Chrome) — тогда ноль кликов для окон, открытых сайтом: они отчитываются и закрываются сами. Поставь Violentmonkey (или Tampermonkey) → открой filter-search.user.js → «установить». v2.3 «тихий»: твой обычный поиск из адресной строки скрипт не перехватывает — авто-режим только у окон с маркером сайта (&fsx=1); на прочих вкладках поисковиков — просто маленькая кнопка «📨 в фильтр» в углу и Alt+S, если сам захочешь отправить.
  3. или расширение-мост — самая надёжная альтернатива менеджеру юзерскриптов: оно знает СВОИ вкладки по tabId и трогает только их — обычные поиски из адресной строки расширение не читает и не трогает вовсе. Папка filter-search-ext в архиве: Chrome/Edge — chrome://extensions → «режим разработчика» → «загрузить распакованное» (работает постоянно); Firefox — about:debugging → «этот Firefox» → «Загрузить временный модуль» → manifest.firefox.json (до перезапуска браузера; постоянно — только после подписи AMO, поэтому в Firefox проще скрипт v2.3 из пункта выше).
резервный канал: выдачу можно просто вставить сюда (Ctrl+A на вкладке → Ctrl+C → Ctrl+V; JSON от закладки вставляется тоже) или перетащить файл (Ctrl+S), или . Каждый новый источник — итог пересчитывается сразу.

как это работает после «искать»
  1. страница открывает окна каскадом (друг под другом) — Google, Яндекс, Bing, DuckDuckGo и Ozon, Avito, AliExpress — оттуда цены в рублях (плюс кнопки для Brave/Mojeek/Marginalia в чипах), и последним — окно поиска с анимацией: оно перекрывает всю стопку и показывает живой прогресс;
  2. в каждом окне выдача разбирается прямо на месте — со скриптом (пункт 2 настройки) без единого клика, без него — один клик по закладке «📨 в фильтр»: результаты, ИИ-ответ (AI Overview у Google, Нейро у Яндекса, Copilot у Bing) и цены летят сюда через postMessage или «вкладку-почтальона»;
  3. окно-анимация загорается чипами источников по мере поступления и закрывается само, когда итог собран; окна поисковиков тоже стараются закрыться сами — если браузер не даёт странице закрыть себя после перехода с поисковика, останется окно «✓ передано» — просто закрой его Ctrl+W, данные уже на главной странице;
  4. две выдачи → итог собирается сам и выглядит как в каталогах: один товар — одна строка, слева название, справа — источники с ценами (цены маркетплейсов — реальная цена карточки; цены, вынутые из текста выдачи, помечены «≈»); перекрёстные подтверждения и медиана рынка считаются между строками;
  5. фильтр скрывает подделки, «Case for X», чужие модели и подозрительные цены — и объясняет каждое скрытие; ИИ-ответы поисковиков показываются отдельной сводкой сверху — как справка, в медиану они не входят.
стадии: ① запрос и перевод → ② твои окна поисковиков (выдача + ИИ-ответы) → ③ сравнение выдач → ④ карточки товаров → ⑤ магазины напрямую (твой IP) → ⑥ фильтр и итог. Всё считается в твоём браузере от твоего лица; страница работает даже из файла (file://); iframe нет, серверов и прокси нет — антибот поисковиков видит обычного тебя.
