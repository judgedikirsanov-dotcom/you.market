технические детали

разовая настройка (1 минута) — закладка «📨 в фильтр товаров» и файлы моста

  1. кнопка-закладка — универсально, любой браузер, без расширений: перетащи эту кнопку на панель закладок (в Firefox: Ctrl+Shift+B — показать панель):
    закладка: 📨 в фильтр
    потом на каждой странице выдачи — один клик по этой закладке: после «искать» сайт открывает одну вкладку («Шаттл»), закладка передаёт её выдачу и ИИ-ответ на главную страницу, и та же вкладка сама идёт к следующему источнику; после последнего — закрывается. На любой другой вкладке выдачи закладка тоже работает. На телефоне: открой закладку из меню закладок.
  2. или пользовательский скрипт (Firefox / Chrome) — тогда ноль кликов: вкладки, открытые сайтом («Шаттл» — в том числе), отчитываются сами и сами идут к следующему источнику. Поставь Violentmonkey (или Tampermonkey) → открой filter-search.user.js → «установить». Скрипт не перехватывает твой обычный поиск из адресной строки: авто-режим только у вкладок с маркером сайта (&fsx=1); на прочих вкладках поисковиков — просто маленькая кнопка «📨 в фильтр» в углу и Alt+S.
  3. или расширение-мост: оно знает СВОИ вкладки по tabId и трогает только их — обычные поиски из адресной строки не читает. Папка filter-search-ext: Chrome / Edge — chrome://extensions → «режим разработчика» → «загрузить распакованное»; Firefox — about:debugging → «этот Firefox» → «Загрузить временный модуль» → manifest.firefox.json (до перезапуска браузера).

файлы выпуска (репозиторий, шаг 5): filter-search-ext.zip — готовая папка расширения · SHA256SUMS.txt — контрольные суммы · страница выпуска — инструкция по установке и состав изменений. Канал сбора страница выбирает сама и показывает его в строке статуса; запасной выбор — в разделе «канал сбора» ниже.

канал сбора

канал выбирает страница под текущий браузер; запасной выбор (для проверки):

порядок в «авто»: локальный помощник (этап 3, появится позже) → расширение-мост → «Шаттл» → окна. «Шаттл»: после «искать» открывается одна вкладка; на каждой выдаче — закладка «📨 в фильтр товаров» (или скрипт-мост сам), вкладка идёт к следующему источнику и после последнего закрывается. Выбранный канал показывается в строке статуса; запасной выбор действует с ближайшего поиска и хранится в этом браузере.

источники текущего поиска

Планировщик выбирает 3–4 источника по намерению: купить → Яндекс, Ozon, Google; б/у → Авито, Яндекс, Google; выбрать → Google, Яндекс, DuckDuckGo; изучить → Google, DuckDuckGo. Остальные — запасные кнопки.

план запроса

Что именно уйдёт в каждый источник: намерение, разобранные сущности, три текста запроса и лестница ослабления. Карточка получает баллы за бренд, модель, категорию, уточнения и атрибуты; три правила скрывают её независимо от баллов: нет бренда запроса, другая модель того же бренда, аксессуар вместо товара.

контрольные запросы — план каждого

Параметры второй волны (P6, P8, P11) не встроены в адреса: их эффект нужно измерить на живой выдаче. Ссылки собраны по текущему запросу — открой, посмотри выдачу и отметь результат (хранится только в этом браузере).

экспорт

как это работает после «искать»

  1. планировщик разбирает запрос: намерение (купить / б/у / выбрать / изучить), категория, бренд, модель, атрибуты, бюджет, исправляет раскладку («ыфмф ф7д» → sava a7l) и выбирает 3–4 источника;
  2. страница выбирает канал сбора и открывает источники: по умолчанию — одна вкладка «Шаттл» с очередью источников (каждому — свой текст запроса); с расширением-мостом поисковики идут под капотом; запасной режим — окна каскадом «друг под другом» и последним окно поиска с анимацией живого прогресса;
  3. на каждой выдаче — один клик по закладке «📨 в фильтр товаров» (со скриптом — без кликов): результаты, ИИ-ответ и цены летят сюда через «страницу-релей» (данные в адресе → BroadcastChannel), релей ведёт вкладку «Шаттла» к следующему источнику, после последнего закрывает её;
  4. две выдачи → итог собирается сам: один товар — одна карточка, снизу — источники с ценами (цены из текста выдачи помечены «≈»); если основных карточек меньше трёх и все источники отчитались — запрос смягчается на один шаг;
  5. фильтр скрывает подделки, «Case for X», чужие модели, обзоры и подозрительные цены — и объясняет каждое скрытие.

🔒 приватно: страница — статический HTML без серверов, прокси и логов. Запросы к магазинам идут с твоего IP (у них CORS открыт); выдача поисковиков попадает на страницу только из твоих вкладок. Отчёт этапа 0 — это файл на твоём диске, ничего не отправляется.

журнал

стадии: ① запрос и план → ② источники по выбранному каналу: «Шаттл» (одна вкладка), мост или окна (выдача + ИИ-ответы) → ③ сравнение выдач → ④ карточки товаров → ⑤ магазины напрямую (твой IP) → ⑥ взвешенная оценка и итог. Всё считается в твоём браузере; страница работает и из файла (file://); серверов и прокси нет.
