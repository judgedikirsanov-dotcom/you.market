# you.market

Репозиторий проекта «честный поиск товаров» (filter-search-web). Поиск идёт от лица пользователя: страница открывает выдачи поисковиков, закладка, пользовательский скрипт или расширение разбирают их в браузере, а фильтрация и ранжирование карточек выполняются локально — без серверов и прокси.

Сайт: <https://judgedikirsanov-dotcom.github.io/you.market>

## Структура

| Путь | Что лежит |
| --- | --- |
| `apps/web/` | Страница, библиотеки моста, закладка, пользовательский скрипт и их тесты |
| `apps/ext/` | Расширение-мост для браузеров на Chromium и на Firefox |
| `apps/helper/` | Локальный помощник — каталог зарезервирован, кода пока нет |
| `apps/api-proxy/` | Прокси с ключами — каталог зарезервирован, кода пока нет |
| `tools/` | Сборщик закладки и тесты библиотеки моста |

## Проверки и сборка

Нужен Node.js 24. Из корня репозитория:

```
node apps/web/tests/web_tests.js
node tools/test_bridge_lib.js
node tools/build_bookmarklet.js
```

Последняя команда пересобирает `apps/web/bookmarklet.js` и вписывает готовую закладку в `apps/web/index.html`; после изменения `bridge-lib.js` её нужно запустить и закоммитить результат.

## Отправка изменений

```
bash push.sh "что изменилось"
```

Первая отправка и все следующие — одна и та же команда: скрипт сам делает коммит и отправляет его в GitHub. Сам `push.sh` в коммит не попадает. Сайт публикуется из этого же репозитория через GitHub Pages (`.github/workflows/publish-web.yml`): после слияния с main — сам; вручную — вкладка Actions → publish-web → Run workflow. Чтобы публикация заработала, один раз включите Pages: Settings → Pages → Source: «GitHub Actions».
